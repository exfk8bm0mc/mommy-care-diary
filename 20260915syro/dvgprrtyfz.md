# 孕妇感冒能喝姜汤吗 吃哪些食物效果好

孕妇在期间身体素质会出现一定的降低，这时如果不注意加强调养，很容易出现感冒的症状，孕妇感冒以后可以喝姜汤，这对孕妇会有很好的治疗效果，有不错的驱寒的作用，除了喝姜汤以外，孕妇在感冒期间吃哪些食物治疗的效果好呢?

1. 红糖姜水，红糖姜水有很好的温胃驱寒的功效，准备适量的红糖，也可以准备几颗大枣，把新鲜的生姜切成片，然后切成丝，把大枣去掉枣核，和红糖一起放入容器当中，加入姜丝，煮半个小时左右，有很好的驱寒和治疗感冒的作用。

2. 孕妇感冒以后，也可以适当的喝些鸡汤，既能够提高身体的免疫力，同时对于治疗和缓解感冒也很有效果，准备嫩鸡一只，收拾干净以后放到水里面煮，加少量的调味品，一定要少放盐，主要是喝清淡的鸡汤，这对于呼吸道感染都有很好的调养保健意义。

3. 生姜萝卜汤，准备生姜丝半两，准备萝卜丝一两，把姜和萝卜切成丝以后，放入适量的水，然后煎煮一刻钟，放入红糖煮沸，在口感合适的情况下趁热喝，有很好的治疗伤风感冒的作用，同时还有调理肠胃的功效。

4. 孕妇在饮食方面应该吃一些清淡而有营养的食物，提高身体的免疫力水平，平时应该多喝汤，多吃一些有作用的水果和蔬菜，这样都能够促进炎性体液尽快的排出，有利于早日恢复健康。

孕妇感冒一定要加强治疗和调养，在感冒期间因为药物治疗的禁忌问题，只要病症不严重，就一定要加强饮食方面的调养，比如多喝一些红糖姜水，适当的喝一些鸡汤，多吃一些水果和蔬菜，禁忌一些油腻性的食物，都能够促进孕妇恢复健康。
